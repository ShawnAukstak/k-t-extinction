# data/

Source data for the simulator. Nothing is downloaded yet; this file describes the intended layout so the research in `docs/research/` has somewhere to land.

Principle: **raw inputs are immutable and cited; everything the app consumes is derived by a script.** If a number in the app can't be traced back through `processed/ → raw/ → docs/research/sources.md`, it doesn't belong in the app.

## Planned layout

```
data/
  README.md                 ← this file
  catalog.yaml              ← (planned) machine-readable index of every dataset: name, source URL,
                              license, citation, version/date fetched, checksum, which docs/research
                              page discusses it
  raw/                      ← untouched downloads, gitignored. Re-fetchable from catalog.yaml.
    paleogeography/         ← PaleoDEM grids, GPlates reconstructions, coastline polygons
    climate/                ← paleoclimate model outputs (NetCDF)
    paleontology/           ← PBDB occurrence dumps, body-mass tables, taxon lists
    impact/                 ← published model outputs (tsunami grids, ejecta, climate response)
    modern/                 ← reference modern data (ETOPO/GEBCO, Blue Marble) if needed for comparison
  processed/                ← derived, app-ready, gitignored (regenerated by scripts/)
    globe/                  ← terrain tiles / heightmaps / land-sea masks at 66 Ma
    biomes/                 ← vegetation raster
    fauna/                  ← curated per-locality species lists with positions, counts, behaviour params
    effects/                ← keyframed/gridded effect fields (blast, thermal, tsunami, dust, temp)
  curated/                  ← SMALL hand-edited files that ARE committed: points of interest,
                              timeline events, species cards, camera presets, caveats text
    timeline.yaml
    points-of-interest.yaml
    species/
```

## Open questions
- Where do large derived assets live for the deployed site? (Object storage with free egress, e.g. Cloudflare R2, vs. committing to the repo under a size limit.) See `docs/tech/`.
- Licensing: most scientific datasets are CC BY or similar, but some paleogeographic atlases are commercial. Every entry in `catalog.yaml` must carry a license field before it is used.
- Format for `curated/`: YAML is proposed for human editability; could be JSON with a schema. Decide when the first real file is written.
